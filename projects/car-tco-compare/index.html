Car TCO Compare

Compare the estimated cost of owning up to six cars, with assumptions you can change and a breakdown you can inspect.

A Key DecisionMake the assumptions editable so the ranking can be challenged.

The Case Study

Problem
Sticker price and monthly payments leave out much of the cost of owning a car. I wanted to compare different vehicles under the same holding period, mileage, and financing assumptions, and inspect what changes the ranking.
What I Built
A car-ownership calculator with a seven-part cost model, side-by-side comparisons, cumulative cost charts, and a snapshot of real listings. A separate email-alert prototype ranks listings by estimated ownership cost.
How It Works
The pure TypeScript calculation engine is separate from the React interface and reused in Car Shopping. Listing snapshots keep the comparator static. Supabase, Resend, and scheduled GitHub Actions support the email-alert prototype with double opt-in.
Where It Stands
The comparator is publicly available. The alert backend is a proof of concept; a commercial subscription service has not launched. This project demonstrates a complete path from a model to an interactive product and a supporting backend.
Evidence and Limits
  • Cost assumptions are illustrative segment-level estimates, not predictions of an individual buyer’s expenses. Listings are snapshots, not guaranteed current inventory.
  • Engine tests cover calculations, depreciation, and vehicle resolution. The model documentation makes the assumptions inspectable.
  • The alerts prototype has a public review record. Historical checks are not a promise of current service reliability.
