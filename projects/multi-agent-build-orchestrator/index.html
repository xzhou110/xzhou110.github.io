The Case Study

Problem
Building with several AI agents creates coordination work: agreeing on interfaces, managing dependencies, resolving conflicting changes, and deciding whether the result actually meets the brief.
What I Built
A reusable build playbook with specialist roles, shared contracts, resumable runs, decision records, and acceptance criteria. Small changes use a smaller process; a full product build gets broader review.
How It Works
I define the outcome and consequential trade-offs. The workflow sequences dependencies, coordinates implementation areas, and checks the integrated result. Claude Code supports the bundled parallel workflow; other assistant environments use the role playbook within their available capabilities.
Where It Stands
Used in Car Shopping and Apartment Shopping. Their public decision and review records show the process applied to real products. The workflow itself remains a private tool.
Evidence and Limits
  • A clean-checkout run caught tests that passed only after a local build. The workflow now requires checking the tests before the build, so local leftovers cannot stand in for a working handoff.
  • The workflow supports AI-assisted implementation; product judgment and acceptance remain human responsibilities.
  • No measured productivity gain or fully autonomous delivery claim is made.
