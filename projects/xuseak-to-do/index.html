An iPhone app for planning the day, managing tasks and habits, and capturing ideas, with offline use and optional account sync.

iPhone App · Private Source

Key DecisionMake the app useful offline; add account sync without making it a prerequisite.

The Case Study

Problem
Tasks, recurring habits, and ideas often live in separate tools. I wanted one daily view that makes the next action clear and works before an account is created.
What I Built
An offline-first iPhone app with Today, To-Do, Habits, Ideas, and Calendar, optional account sync, and an interactive Home Screen widget. The work includes product design, data modeling, native interaction refinement, and release preparation.
How It Works
A pure TypeScript engine sits behind a React Native interface. Local persistence works independently of the account layer; sync merges changes through a separate adapter. I direct product and design decisions, review AI-assisted implementation, and test the installed experience.
Where It Stands
Installed through TestFlight and submitted for App Review. Review follow-up is in progress; there is no public App Store release to download yet.
Evidence and Limits
  • Independent review caught second-device default preferences blocking sync and stale writes replacing newer changes. Per-key merging and regression tests now cover those cases.
  • Automated checks are separate from physical-device acceptance. Two-device sync and account-deletion acceptance remain open.
  • The preview uses fictional tasks. No account data, personal task list, or private source is included.
