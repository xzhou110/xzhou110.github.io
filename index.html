How I Build

I use AI agents to help implement and review. I own the problem framing, product choices, and the decision about what is ready to ship.

01

Start with the Decision

Identify who needs help and what they need to do. Make the assumptions, data limits, and smallest useful workflow explicit.

02

Build for Change

Keep domain rules separate from the interface and services. Write down trade-offs, preserve saved work, and reuse code when real repetition justifies it.

03

Look for What Breaks

Use tests, independent review, and the installed or deployed app. In Car Shopping, review caught an unsafe URL import; I removed it and kept a regression test.
