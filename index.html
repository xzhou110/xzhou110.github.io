How I Build

I use AI agents for implementation and review. I’m responsible for the product direction, design choices, and release decisions.

01

Define the Problem

Start with the person using the product and the decision they need to make. Identify the assumptions, data limits, and smallest useful workflow.

02

Build for Change

Keep product rules separate from the interface and services. Record trade-offs, protect saved work, and reuse code when the same need appears across apps.

03

Test the Result

Check the result through tests, independent review, and the installed or deployed app. In Car Shopping, review caught an unsafe URL import; I removed it and kept a regression test.
